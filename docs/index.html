Surprise Mode

Your pet earns gear. Then it surprises you.

Finish tasks and your pet unlocks accessories — glasses, a dev cap, a coffee cup with animated steam, a gold crown. Reach 200 tasks and Surprise Mode kicks in: your local agent generates 150 unique pixel accessories and equips a fresh combo every few tasks.

  • 20 base accessories across 4 slots: head, face, hand, back
  • 150 more generated locally, unique to you
  • Star the repo and they all unlock at once

Features

It doesn't just sit there. It keeps up with your agent.

Every state your agent goes through, the pet shows — in plain words, right above its head.

Live tool bubbles

The bubble shows the agent's actual tool call — Reading server.mjs, Running tests — not just "Running". You know what it's doing without switching windows.

It talks back

Double-click the pet to send it work. When a risky command needs approval, it asks Allow / Deny right in the bubble — no digging through menus.

Background moon state

When the foreground chat is idle but background tasks run, the pet rests with a moon badge and a lavender halo. Click the task stack to jump to any session.

It gets bored

Leave it alone and it wanders off, looks around, and falls asleep with Zzz. Type fast enough and stars spin over its head. Any keystroke wakes it up.

Community workshop

Browse, star, and one-click install community pets inside Settings. Or make your own from a single image — no spritesheet required.

Growth accessories

Your pet earns gear as you finish tasks. Surprise Mode adds 150 locally generated accessories on top of the 20 base ones.

Peeks, then hides

Drag it to a screen edge and it peeks out with half its body. During fullscreen games or videos it disappears — and peeks back when something needs you.

Click to jump back

Click the pet or its bubble and you're straight back in the right conversation, even if Antigravity is minimized.

Always in sync

One glance tells you the whole story.

Install

Up and running in a minute.

  1. Download the latest release and extract it to your Antigravity plugins folder.

    Windows: %USERPROFILE%\.gemini\config\plugins\antigravity-pet
    macOS: ~/.gemini/config/plugins/antigravity-pet

  2. Run the one-click launcher.

    Windows (PowerShell): .\build.ps1 -Launch
    macOS: chmod +x build.sh && ./build.sh --launch

  3. Open Antigravity. The pet appears on your desktop.

    Press Win + Alt + P (⌥ + ⌘ + P on macOS) to show or hide it anytime.

Ask your AI agent to install it

Copy this prompt and paste it into your agent's chat — it installs the pet for you:

Install Antigravity Pet for me: run agy plugin install https://github.com/Wlaeg/antigravity-pet, confirm the plugin folder exists, build and launch it once, and tell me the toggle shortcut. Windows: %USERPROFILE%\.gemini\config\plugins\antigravity-pet, .\build.ps1 -Launch, Win + Alt + P. macOS: ~/.gemini/config/plugins/antigravity-pet, chmod +x build.sh && ./build.sh --launch, Option + Command + P. If the install fails, download the latest release or clone the repo and build from source instead.

FAQ

Questions, answered.

What is Antigravity Pet?

A free, open-source pixel desktop pet for Google Antigravity on Windows and macOS. It sits on your desktop and shows what your agent is doing, live.

How do I install it?

Download the latest release and run the one-click launcher, or install with agy plugin install https://github.com/Wlaeg/antigravity-pet.

Does it work on macOS?

Yes — macOS 12+ on Apple Silicon and Intel, built with the native Swift overlay.

Is it free?

Yes, MIT licensed. No account, no subscription, no telemetry.
