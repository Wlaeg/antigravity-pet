A pixel desktop pet that shows what your Antigravity agent is doing, live.

Antigravity Pet lives on your desktop and mirrors your agent in real time — working, waiting for input, done, or stuck — so you can tell at a glance without keeping the Antigravity window in front of you.

Why a pet?

💬 Live tool bubbles

The bubble above your pet shows the agent's current tool call — Reading server.mjs, Tests passed — no window switching.

👆 It talks back

Double-click the pet to dispatch a task. Risky tool calls ask Approve / Deny right in the bubble.

🌙 Background moon state

When the foreground chat is idle but background tasks run, the pet rests with a moon badge and a task switcher.

🎒 Community workshop

Browse, install, and share community pet packs inside Settings. One static PNG is enough to make your own pet.

✨ Surprise Mode

Finish 200 tasks (or star the repo) and your local agent generates 150 unique pixel accessories across 4 gear slots.

🫥 Stays out of the way

Edge peeking, fullscreen auto-hide, typing sync, boredom and naps. No taskbar or Dock clutter, zero telemetry.

Install in three steps

  1. Download the latest release and extract it to your Antigravity plugins folder.
  2. Run the one-click launcher (build.ps1 -Launch on Windows, ./build.sh --launch on macOS).
  3. Open Antigravity. The pet appears on your desktop — press Win + Alt + P (⌥ + ⌘ + P on macOS) to show or hide it.

FAQ

What is Antigravity Pet?

A free, open-source pixel desktop pet for Google Antigravity on Windows and macOS. It sits on your desktop and shows what your agent is doing, live.

How do I install it?

Download the latest release and run the one-click launcher, or install with agy plugin install https://github.com/Wlaeg/antigravity-pet.

Does it work on macOS?

Yes — macOS 12+ on Apple Silicon and Intel, built with the native Swift overlay.

Is it free?

Yes, MIT licensed. No account, no subscription, no telemetry.
