# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.x     | yes       |

## Reporting a Vulnerability

If you find a security issue in Antigravity Pet, please open a GitHub issue in this repository or email wlaeg233@gmail.com with a description of the problem. Please do not open a public issue for a vulnerability that could be exploited — describe it privately first and allow reasonable time for a fix before any public disclosure.

Thanks for helping keep Antigravity Pet safe.
